# SQL Interactive Tutor

An interactive web application designed to guide students through SQL Database labs (Labs 3 to 11).

## Features

* **Interactive SQL Practice**: Write and verify SQL queries directly in the application with instant feedback.
* **Comprehensive Modules**: Covers basic queries, joins, subqueries, group functions, constraints (DDL/DML), and a final exam preparation lab.
* **Quizzes**: End-of-chapter quizzes to test your understanding of each topic.
* **Persistent Progress Saving**: Automatically saves your current module, lesson, and completed sections to local storage, allowing you to resume where you left off.
* **Progress Resetting**: Allows you to clear all progress data and start fresh using the reset button.

## How to Run

Open the `sql_lab3_tutor.html` file in any modern web browser. No installation or server setup is required.
